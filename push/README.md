# سيرفر إشعارات منبهات الأدوية (Cloudflare Workers - مجاني)

بيبعت إشعار على موبايل العميل **في ميعاد الجرعة بالظبط** حتى لو البرنامج مقفول.
بيشتغل كل دقيقة، فأقصى تأخير ممكن حوالي دقيقة. مفيش كارت بنكي مطلوب.

## خطوات التشغيل (مرة واحدة)

1. اعمل حساب مجاني على https://dash.cloudflare.com
2. على جهازك (محتاج Node.js):
   ```
   npm install -g wrangler
   wrangler login
   ```
3. ادخل فولدر `push` وأنشئ قاعدة البيانات:
   ```
   cd push
   wrangler d1 create dawaay-push
   ```
   انسخ `database_id` اللي هيظهر وحطه في `wrangler.toml` مكان `CHANGE_ME`.
4. أنشئ الجداول:
   ```
   wrangler d1 execute dawaay-push --remote --file=schema.sql
   ```
5. اعمل مفاتيح الإشعارات:
   ```
   node gen-vapid.js
   ```
   - الـ `VAPID_PUBLIC` حطه في `wrangler.toml` (وهتحطه كمان في `index.html`).
   - غيّر `VAPID_SUBJECT` في `wrangler.toml` لإيميلك.
6. حط المفتاح السرّي (الصق سطر الـ JWK كامل لما يسألك):
   ```
   wrangler secret put VAPID_PRIVATE_JWK
   ```
7. انشر:
   ```
   wrangler deploy
   ```
   هيطلعلك رابط زي `https://dawaay-push.xxxx.workers.dev`.
8. في `index.html` املا السطرين:
   ```js
   const PUSH_URL = 'https://dawaay-push.xxxx.workers.dev';
   const VAPID_PUBLIC = '...';
   ```
   وارفعه على GitHub.

## التجربة
- افتح البرنامج على الموبايل (ويفضّل بعد التثبيت)، فعّل منبه لدواء بعد دقيقتين، واسمح بالإشعارات، واقفل البرنامج.
- لو مجاش إشعار: `wrangler tail` بيوريك اللي بيحصل في السيرفر وقت الإرسال.

## تحديث السيرفر (لو عندك نسخة قديمة منصّبة)
1. استبدل `worker.js` و`schema.sql` بالجداد (من `dawaay-push-update.zip` أو من الريبو). **متستبدلش `wrangler.toml`** لأن فيه إعداداتك.
2. من فولدر `push`:
   ```
   wrangler d1 execute dawaay-push --remote --file=schema.sql
   wrangler deploy
   ```

## قراءة الصور والروشتات بالذكاء الاصطناعي (اختياري ومجاني)
بتخلّي البرنامج يقرا العلب والشرايط وخط الدكاترة بدقة أعلى بكتير من القراءة العادية. المفتاح بيفضل سرّ في Cloudflare (مش في الكود).
1. اعمل مفتاح مجاني من https://aistudio.google.com (Create API key).
2. من فولدر `push`:
   ```
   wrangler d1 execute dawaay-push --remote --file=schema.sql
   wrangler secret put GEMINI_API_KEY
   wrangler deploy
   ```
   (الأمر التاني بيسألك تلصق المفتاح.)
3. خلاص. مفيش حاجة تتغير في `index.html`. لو المفتاح مش موجود، البرنامج بيستخدم القراءة العادية.
- الحد الافتراضي 30 قراءة في الساعة لكل جهاز (`READ_LIMIT` في `wrangler.toml` لو عايز تغيّره)، وكل الاستخدام ضمن الطبقة المجانية لـ Gemini.
- لو ظهر خطأ من اسم الموديل، ضيف في `[vars]` سطر `GEMINI_MODEL = "اسم_موديل_فلاش_حالي"`.
- الصور بتروح لجوجل للقراءة، فمتصوّرش بيانات شخصية.

## التنبيه المتكرر
- التنبيه بيتكرر **كل دقيقة** (5 مرات كحد أقصى) لحد ما تضغط **أخدته** أو **بعد 10 دقايق** أو تشيل الإشعار.
- علشان صوته يبقى عالي كالمنبه: إعدادات أندرويد ← التطبيقات ← دوائي (أو Chrome) ← الإشعارات ← اختار فئة التنبيهات ← **Urgent/Pop on screen** ← **Sound** واختار نغمة المنبه.

## ملحوظات
- مهم في أندرويد: إعدادات التطبيق ← البطارية ← "بدون قيود"، وتأكد إن إشعارات كروم/التطبيق شغالة.
- الإشعار صوته صوت إشعارات الموبايل العادي، مش منبه الساعة.
- السيرفر بيخزّن: رابط اشتراك الموبايل، واسم الدواء ومواعيده. مفيش اسم ولا تليفون العميل.
- الحدود المجانية بتكفي مئات المستخدمين (الـ Worker بيشتغل 1440 مرة في اليوم فقط).
