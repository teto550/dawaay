# قاعدة الأدوية العالمية (أمريكا - FDA)

الأداة دي بتحوّل ملفات FDA الرسمية (مجانية ومفتوحة، Public Domain) لملفين البرنامج بيقراهم لوحده:
- `world.json`: أسماء الأدوية (اسم الدواء + التركيز + الشكل + المادة الفعالة + الشركة)
- `world-barcodes.json`: الباركود (UPC-A) لكل عبوة، اتحسب من رقم الـ NDC الرسمي

## الخطوات (على اللابتوب)

1. نزّل ملف الـ NDC من FDA (النسخة النصية Text):
   https://www.accessdata.fda.gov/cder/ndctext.zip
   (لو اللينك اتغيّر: ابحث عن "NDC Database File" في موقع FDA وحمّل نسخة الـ text)
2. فُك الضغط، هتلاقي `product.txt` و `package.txt`.
3. حط `build-world.mjs` جنبهم، وافتح التيرمينال في نفس الفولدر:
   ```
   node build-world.mjs product.txt package.txt
   ```
   هيطلع `world.json` و `world-barcodes.json` ويكتب عدد الأدوية والباركودات.
4. ارفع الملفين على GitHub في نفس مكان `index.html` (Add file ← Upload files).
   - الرفع من المتصفح بيقبل لحد 25 ميجا للملف. لو أي ملف أكبر، ارفع بـ git.
5. افتح البرنامج. مفيش حاجة تانية تتغيّر.

## البرنامج بيستخدمهم إزاي
- بيحمّلهم **بس لما يحتاجهم**: لو بحثت عن دواء ومالقاش غير أقل من 3 نتايج في القاعدة المصرية، أو صوّرت باركود مش معروف.
- الباركود بيتدوّر عليه في القاعدة المصرية الأول، وبعدين في العالمية.
- لو الملفين مش موجودين، البرنامج بيشتغل عادي بالقاعدة المصرية.

## ملحوظات
- الباركود هنا مبني على الـ NDC الأمريكي (UPC-A اللي بيبدأ بـ 3). عبوات أوروبا والدول التانية ليها نظام تاني ومش موجودة هنا.
- أغلب الأدوية في مصر محلية، وبتتعرف من القاعدة المصرية.
- الأداة بتستبعد: الأدوية الموقوفة، وعبوات العينات، والأدوية الحيوانية ومشتقات الدم.
- أعد تشغيل الأداة كل فترة بملف FDA الجديد علشان تتحدّث (FDA بيحدّثه يوميًا).
